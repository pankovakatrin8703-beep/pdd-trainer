# ПДД Trainer — личное мобильное приложение

Это самостоятельный PWA-тренажёр для личного использования. Прогресс хранится на устройстве через localStorage. Интернет для самой тренировки после первой загрузки не нужен, если приложение установлено как PWA.

## Что внутри
- мобильный интерфейс под одну руку;
- онбординг: Россия → уровень → дата экзамена;
- Главная / Учёба / Тренировка / Экзамен / Профиль;
- режимы 10/20/50 вопросов;
- повторение ошибок;
- локальная статистика и серия;
- справочник знаков в демо-режиме;
- установка на домашний экран как приложение;
- офлайн-кэш.

## Важно
Вопросы в этой личной версии являются учебной демонстрационной базой и не являются официальными экзаменационными билетами ГИБДД. Перед использованием для подготовки к реальному экзамену контент необходимо проверить по актуальной редакции ПДД РФ и официальным материалам.

Нормативная база интерфейса: ПДД РФ — Постановление Правительства РФ от 23.10.1993 № 1090; в проекте указана редакция от 28.08.2026.

## Установка на телефон
1. Разместите папку на HTTPS-хостинге.
2. Откройте адрес на телефоне.
3. iPhone: Safari → Поделиться → «На экран Домой» → включить «Открывать как веб-приложение» → Добавить.
4. Android: Chrome → ⋮ → «Установить и создать ярлык» → Установить.
